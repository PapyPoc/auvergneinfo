Pour publier, ouvre le dépôt GitHub puis utilise le formulaire **Issues → New issue → Publier un article**.

Le workflow transforme automatiquement le formulaire en fichier Markdown dans `src/data/posts/`, ferme la demande de publication puis déclenche le déploiement.

Tu peux aussi modifier directement un fichier depuis l'éditeur web de GitHub.
