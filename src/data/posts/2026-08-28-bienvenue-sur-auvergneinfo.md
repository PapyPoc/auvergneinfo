Bienvenue sur **AuvergneInfo.fr**.

Le site fonctionne sans CMS traditionnel : chaque publication est un fichier Markdown conservé dans GitHub.

## Comment sont publiés les articles ?

1. Un article est ajouté ou modifié dans GitHub.
2. GitHub Actions lance automatiquement la construction du site.
3. Astro transforme le Markdown en pages HTML statiques.
4. GitHub Pages publie la nouvelle version.

Cette architecture permet de conserver un historique complet des modifications tout en proposant un site très rapide.
