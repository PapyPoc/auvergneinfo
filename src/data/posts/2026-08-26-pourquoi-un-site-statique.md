Un site statique sert principalement des fichiers HTML, CSS et JavaScript déjà générés.

Cela signifie qu'aucune base de données n'est interrogée pour afficher un article, et qu'aucun moteur PHP n'est nécessaire côté hébergement public.

## Les bénéfices

- chargement rapide ;
- moins de services exposés ;
- déploiement reproductible ;
- historique Git complet ;
- retour arrière simple en cas de problème.
